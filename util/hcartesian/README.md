## 笛卡尔积 组合

两个集合之间所有可能的有序对的集合

```go
var (
	p1 = []any{282814}                         // 参数1
	p2 = []any{282816, 282817}                 // 参数2
	p3 = [][]any{{"a", "b"}, {282816, 282817}} // 参数3(二维数组)
)

a1 := CartesianProduct(p1, p2) 	// 组合后: [[282814,282816],[282814,282817]]
a2 := CartesianProduct(p3...) 	// 组合后: [[282814,282816],[282814,282817],["aaaa",282816],["aaaa",282817]]
```
